# Range Size Does Not Predict Climatic Niche Breadth in Congeneric *Gymnosporia* and *Cassine* (Celastraceae) from India

Code, figures, and supporting data accompanying the manuscript by **Sanskruti Pandit, Anandi Korde, and Mandar Datar** (Rock Outcrop Ecology Lab, MACS-Agharkar Research Institute, Pune).

This study compares the climatic niches and geographic ranges of five species of *Gymnosporia* and *Cassine* across India:

* *Gymnosporia rothiana*
* *Gymnosporia emarginata*
* *Gymnosporia senegalensis*
* *Cassine glauca*
* *Cassine paniculata*

The analysis is based on **628 cleaned occurrence records** and **19 CHELSA v2.1 bioclimatic variables**. Climatic niche differences and breadth were assessed using principal component analysis (PCA), PERMANOVA, and convex-hull approaches in geographic and climatic space.

### Code

The analysis scripts are numbered according to their intended execution order and are located in the `Code/` directory.

| Script                                | Description                                                                                                                                                                                                                       |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `01_merge_clean_coordinates.py`       | Merges herbarium and literature records with GBIF downloads, removes exact-coordinate duplicates, and identifies records falling outside the Indian national boundary. Produces the final cleaned occurrence dataset (`n = 628`). |
| `01b_check_points_in_india.py`        | Performs a point-in-polygon check of occurrence records against the national boundary and calculates distance to the boundary for records falling outside India.                                                                  |
| `02_extract_chelsa_climate.py`        | Extracts values for all 19 CHELSA v2.1 bioclimatic variables at each occurrence location.                                                                                                                                         |
| `03_pca_permanova_analysis.py`        | Standardises the 19 climatic variables, performs PCA, retains five principal components for subsequent analyses, estimates species-level climatic niche centroids and breadth, and performs PERMANOVA with 999 permutations.      |
| `04_geographic_finescale_analysis.py` | Calculates geodesic convex-hull geographic range areas, pairwise geographic and climatic hull overlap, nearest heterospecific-neighbour distances, and the relationship between geographic range size and climatic niche breadth. |
| `05_make_figures.py`                  | Generates the four figures presented in the manuscript at 220 dpi.                                                                                                                                                                |

### Software requirements

The analysis was conducted using Python. The following packages are required:

```bash
pip install numpy pandas scikit-learn matplotlib openpyxl rasterio geopandas shapely pyproj contextily
```

### Reproducing the analysis

The scripts were originally developed using a flat project directory in which the coordinate data, India boundary shapefile, figure directory, and CHELSA raster directory were located as siblings of `Code/`.

In this repository, these files have been reorganised under `Raw data/` and `images/`. Consequently, some file paths in scripts `01_merge_clean_coordinates.py`, `01b_check_points_in_india.py`, and `05_make_figures.py` may need to be updated before the pipeline can be executed directly from the repository.

The complete outputs generated by the analysis pipeline are retained in `Code/Results/`. These files allow the numerical results and figures reported in the manuscript to be inspected without rerunning the complete pipeline.

## Data

### Occurrence data

The final cleaned occurrence dataset is provided as:

`Raw data/cleaned_coordinates_master.xlsx`

The workbook contains one sheet per species and includes the final **628 occurrence records** used in the analyses.

A point-level audit of records that were removed or added during data cleaning is provided in:

`Raw data/removed_and_added_points.xlsx`

The original occurrence records consisted of GBIF downloads together with herbarium and literature records. GBIF was used as one of the primary sources of occurrence data.

GBIF: [Global Biodiversity Information Facility (GBIF)](https://www.gbif.org/?utm_source=chatgpt.com)

### Geographic boundary

The national boundary used for the spatial point-in-polygon check is provided in:

`Raw data/Indiastate_shapefile/India_Country_Boundary.shp`

The boundary was used to identify occurrence records located within India. Occurrence coordinates were transformed to the appropriate coordinate reference system before spatial testing.

### Climate data

The extracted climatic data are provided in:

`Raw data/occurrence_climate_CHELSA.csv`

This file contains the values of the **19 CHELSA v2.1 bioclimatic variables** extracted at the occurrence locations.

The original CHELSA raster layers are not redistributed in this repository. Users wishing to reproduce the climate extraction should obtain the corresponding CHELSA v2.1 layers independently and provide them to `02_extract_chelsa_climate.py`.

The climatic data should be cited according to the original CHELSA publication:

Karger, D. N., et al. (2017). Climatologies at high resolution for the earth's land surface areas. *Scientific Data*, 4, 170122.
